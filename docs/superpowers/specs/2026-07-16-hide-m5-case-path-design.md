# M5 案例库隐藏路径与 Case ID 设计

## 背景

M5 案例库页面当前会展示案例的 `source_path` 和 `case_id`，空状态文案也会暴露 M5 案例文件所在目录。用户要求这些信息不再出现在界面中。

## 目标

- M5 案例列表不显示 `source_path`。
- M5 案例列表不显示 `case_id`。
- M5 案例库空状态不显示具体目录路径。
- 保留案例名称与项目类型展示。
- 不修改后端接口、案例数据结构、案例匹配和 PPT 生成逻辑。
- 不影响“完整 PPT 案例库”页签现有展示。

## 实现方案

仅修改 `frontend/app/views/CaseLibraryView.tsx`：

1. 删除 M5 案例条目中的 `case_id` 文本节点。
2. 删除 M5 案例条目中的 `source_path` 文本节点。
3. 将空状态文案由具体目录检查提示改为不包含路径的通用提示。
4. 添加或更新前端静态结构测试，验证 M5 案例区域不再渲染上述字段和目录文案。

## 验证范围

按照项目要求只运行相关测试：

- 前端静态结构测试中与 `CaseLibraryView` 相关的测试。
- 必要时运行前端 TypeScript 类型检查，确认 JSX 修改没有引入编译问题。

不运行后端或全量端到端测试。

## 风险控制

`case_id` 和 `source_path` 仍保留在接口响应和前端对象中，只是不渲染，因此不会影响案例识别、筛选、匹配或后续生成流程。
